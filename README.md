# Automotive Temperature Monitoring Testing

## Project Overview

This project demonstrates a software testing
workflow for an automotive engine temperature
monitoring module.

## Objectives

- Analyze software requirements
- Design functional test cases
- Execute tests and document results
- Identify and report defects
- Prepare a software test summary

## Scope

The project focuses on the temperature
evaluation logic using a Python simulator.

CAN communication and real ECU integration
are outside the scope of Week 1.

## Technologies

- Python
- Git
- Markdown
- CSV
- Pytest (introductory use)
